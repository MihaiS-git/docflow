Summary

The strongest problems are configuration drift in backend schema management and sensitive runtime data committed into the repository. The frontend also has multiple duplication points in the audit stream layer, and the repo currently carries tracked generated/vendor artifacts despite ignore rules that should have prevented them.

The codebase is functional, but it is accumulating maintenance drag through stale config files, duplicated metadata, inactive tests, and environment-specific values that are embedded directly in source-controlled files.

High

Description: The backend defaults to spring.jpa.hibernate.ddl-auto=create while Flyway is disabled in the base application config, but Docker Compose overrides Hibernate to update.
